# Trip Planner

A lightweight, fully client-side **Trip Planner** app built with vanilla HTML, CSS, and JavaScript.

## Features

- **Create & manage trips** — destination, dates, budget, and notes
- **Itinerary** — add day-by-day activities with times and descriptions, grouped by date
- **Packing list** — categorised items with a check-off progress bar
- **Budget tracker** — log expenses by category, see real-time remaining balance
- **Persistent storage** — all data saved to `localStorage` (no server needed)
- **Responsive** — works on desktop and mobile

## Usage

Open `index.html` directly in any modern browser — no build step or server required.
